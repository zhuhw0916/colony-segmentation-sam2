# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-17

- Added classical OpenCV and scikit-image colony-counting baselines.
- Added SAM2 trained/base benchmarking with configurable preprocessing.
- Added shared SAM2 mask postprocessing and evaluation metrics.
- Added compressed mask export, count CSV, and optional visual overlays.
- Added project documentation, tests, CI, and MIT licensing.
