# Security policy

## Supported versions

Only the latest version on the default branch is actively maintained.

## Reporting a vulnerability

Do not post credentials, private images, model weights, or an exploitable
vulnerability in a public issue. Please contact the repository maintainer
privately through GitHub with:

- a short description of the issue;
- affected files and versions;
- reproduction steps or a minimal proof of concept;
- the impact you observed.

This project processes local images and does not provide a hosted service. Do
not include patient-identifying or otherwise sensitive images in bug reports.
